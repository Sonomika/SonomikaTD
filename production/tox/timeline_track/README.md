# timeline_track.tox

An empty timeline for Sonomika. Put it in a cell with **Add Timeline Tox** (timeline strip), then select or launch it:
the timeline shows its own arrangement - audio clips on the waveform lane, video / tox clips on rows L1-L3.
It has no parameters and no picture of its own (transparent output).

Set the length on the timeline strip: drag the Length field, or drag the end marker on the ruler.
It also grows automatically when an audio clip runs past the end.
