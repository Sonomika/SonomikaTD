SAVE YOUR PERFORMANCE SETS HERE

Use SonomikaTD's Settings > Sets tab to save and open performance sets.

Keep saved set files in this folder so they remain alongside the release:

release/sets

Performance sets use the .json file format. They store the grid layout,
scenes, loaded asset paths, effect parameters, mappings, and related settings.

Note: Set files reference videos and TOX files; they do not embed those files.
If an asset is moved or removed, SonomikaTD will show the cell as "missing"
until it is relinked.
