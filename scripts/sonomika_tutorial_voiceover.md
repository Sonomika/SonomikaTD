# Sonomika for TouchDesigner Tutorial

## Introduction

Welcome to Sonomika for TouchDesigner, a real-time tool for creating and
performing live visuals.

## Grid

This is the performance grid. Each cell can contain a video or a TouchDesigner
effect.

The bottom row is the base visual layer. The rows above are effect layers.

## Rows

Right-click a layer label to add or remove effect rows.

## Columns

Columns let you prepare different visual combinations and switch between them
while performing.

Right-click a column heading to insert, copy, paste, or clear a column.

## Cell controls

When you select a cell, its controls appear on the right. The Base tab contains
the main controls for customizing the selected video or effect.

You can also load multiple effects into one cell and chain them together.

## Cell menu

The cell menu lets you reload or relink the file, edit a TOX, adjust performance
options, copy and paste, or remove the cell.

## Settings

The Settings panel controls the wider performance setup.

Canvas controls the output size.

Sets saves and loads complete performances.

OSC connects external software, while Grid OSC provides remote control of the
performance grid.

Pulse provides timing signals for animation.

Audio enables sound-reactive visuals.

MIDI connects hardware controllers.

Fade controls transitions between cells and columns.

Performance balances visual quality and playback speed.

About contains version and project information.
